PHP-Nuke: Web Portal System
===========================


Welcome to PHP-Nuke!

First of all, thanks a lot for downloading this software, I hope that you
enjoy it.

PHP-Nuke is free software, released under GNU GPL Licence version 2.0
(see COPYING file for details)

PHP-Nuke was the result of many years administrating a news site called
Linux Preview (http://linuxpreview.org) by the original code author Francisco Burzi.
Around August 1998, he wrote some code in Perl called NUKE and used it for about 1 year,
then his site got so big, he needed a more powerful system and decided
to use Slash, the same used in Slashdot site.

Fransisco then discovered Thatware, a good project to have a news site using PHP.
He learned PHP in less than a week, which reflects some of the buggy and poor coding style
and started to modify the original Thatware software.

On August 17, 2000 he sold LinuxPreview.org to LinuxAlianza.com and dedicated his time
 to the development of PHP-Nuke.

From January 2001 to January 2002, PHP-Nuke had been financially supported by
MandrakeSoft, the folks that made Mandrake Linux.

After much criticism from the phpNuke community for not installing security patches,
using old PHP coding methodologies, not supportng the community, the phpNuke website
was sold in December 2007 to an undisclosed buyer.
The new owner left the website up to make money from donations and advertising but
despite an announcement in December 2007 of "a new version is coming soon", at the
time I write this (Summer of 2009) no versions after 8.1 have been released.

The SourceForge Project for phpNuke was taken over by myself in 2007 after contacting
the original author Francisco Burzi.
